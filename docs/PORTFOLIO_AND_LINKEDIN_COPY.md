# DevCV AI — Portfolio and LinkedIn Copy

## Portfolio Project Card

**Title:** DevCV AI

**Status label:** Private Beta

**Short description:** A privacy-first resume workspace where users control exactly when a draft is saved, loaded, or deleted. Built with Next.js, Supabase Auth/RLS, Zod validation, and a server-side AI Gateway integration.

**Verified highlights:**

- Protected authentication flow with email confirmation enabled and a configured callback route.
- Owner-scoped resume history backed by Supabase Row Level Security.
- Explicit save, reload, and delete controls; no automatic raw-resume persistence.
- Clearly labelled sample feedback that cannot be stored as a real AI analysis.
- Server-side Vercel AI Gateway integration with no browser-exposed provider key.

**Honest beta disclosure:** Live AI execution is currently gated by Vercel account verification. The project is shown as a private beta foundation, not as a completed public AI service.

**Tech stack:** Next.js 16, React 19, TypeScript, Tailwind CSS, Supabase Auth, PostgreSQL, Row Level Security, Zod, Vitest, Vercel AI Gateway.

**Live demo:** https://devcv-ai-blue.vercel.app

**Repository:** Private source repository; code access available on request where appropriate.
